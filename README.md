# Parallel-Programming-OpenMP-MPI-CUDA-

A collection of high-performance implementations focusing on shared-memory (OpenMP), distributed-memory (MPI) and GPU-accelerated computing (CUDA) in C/C++

Measured speedup across varying thread/process counts, up to 16 threads/processes on multi-core system.

## Benchmark Simulations

1. **Julia Set Fractal Generation:** Accelerated complex plane iteration mapping.
2. **3D Poisson Equation (Feynman-Kac Solver):** Parallelized stochastic Monte Carlo random-walk path simulations.
3. **Molecular Dynamics Engine:** Accelerated inter-particle force and energy computations in discrete time steps.
